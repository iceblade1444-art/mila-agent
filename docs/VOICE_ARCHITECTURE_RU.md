# Голосовая архитектура MILA без LiveKit

## Решение

MILA использует прямое защищенное подключение телефона к Gemini Live API.
LiveKit, медиасерверы и платные комнаты не нужны.

```text
Телефон                         VM 105                         Gemini
   |                               |                              |
   |-- вход в аккаунт MILA ------->|                              |
   |-- запрос одноразового токена ->|-- Gemini API key ---------->|
   |<-- короткий токен -------------|<-- ephemeral token ---------|
   |                                                              |
   |========== отдельный защищенный WebSocket пользователя ======>|
   |   микрофон 16 kHz PCM             голос 24 kHz PCM            |
```

## Почему это масштабируется

- У каждого пользователя собственная сессия Gemini, без общих комнат.
- Аудио не проходит через VM 105, поэтому сервер не становится узким местом.
- VM 105 хранит ключ Gemini, учетные записи, подписки, лимиты и историю.
- Приложение получает только одноразовый ограниченный токен и не содержит
  постоянный Gemini API key.
- Количество одновременных разговоров определяется лимитом Google-проекта,
  который можно повышать вместе с тарифным уровнем API.

## Надежность разговора

- Микрофон отправляет PCM16 mono 16 kHz небольшими блоками.
- Android воспроизводит ответ через постоянный нативный `AudioTrack` 24 kHz.
- `turnComplete` фиксирует реплику, но не обрывает аудиобуфер.
- При перебивании пользователя очередь звука очищается сразу.
- Context window compression ограничивает рост истории и стоимости.
- Session resumption продолжает разговор после плановой смены WebSocket.

## Что остается перед публичным запуском

1. Включить собственную регистрацию и авторизацию MILA на VM 105.
2. Хранить Gemini API key только в серверном `.env`.
3. Выдавать токены только активным пользователям и добавить дневные лимиты.
4. Собирать метрики длительности, ошибок и расхода без записи голоса.
5. Перейти на платный уровень Gemini API перед подключением многих клиентов.
