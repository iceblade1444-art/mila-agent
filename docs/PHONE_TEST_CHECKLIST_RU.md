# MILA phone test checklist

Тестовая сборка с Gemini key предназначена только для личной проверки.
Не публикуй APK и не отправляй его посторонним.

## Установка

1. Установи `dist/MILA-1.0.3-stable-onboarding-test.apk` на Android-телефон.
2. Разреши установку из неизвестных источников, если Android попросит.
3. При первом запуске разреши микрофон и уведомления.

## Проверка по пунктам

1. Первый запуск: приложение открывается без белого/чёрного экрана.
2. Главный экран: видны приветствие, orb, нижняя навигация.
3. Settings -> AI Providers: Server URL равен `https://agent.milanapremium.uz`.
4. Settings -> Check for Updates: нет ошибки подключения.
5. Voice: нажми Start talking и скажи коротко: `Привет, ты меня слышишь?`
6. Voice: MILA должна перейти из listening в thinking/speaking и ответить голосом.
7. Voice: после первого ответа скажи второй вопрос: `Расскажи коротко, что ты умеешь`.
8. Voice: второй ответ тоже должен быть голосом, не только текстом.
9. Interrupt: пока MILA говорит, начни говорить сам. Она должна остановить ответ и слушать.
10. End conversation: нажми End conversation, затем открой Chat и проверь, сохранился ли текст разговора.
11. Text chat: напиши простой вопрос и проверь текстовый ответ.
12. Memory: после разговора проверь, не появилось ли лишних/странных записей.

## Что прислать после теста

- Модель телефона и версия Android.
- На каком пункте сломалось.
- Точный текст ошибки, если она появилась.
- Был ли голос в первом и втором ответе.
- Работал ли interrupt во время речи MILA.
